# ביטוח בקליק

מערכת פרטית לניהול סוכנות ביטוח בעברית ובכיוון RTL: לקוחות ובני משפחה, פוליסות, תביעות, מסמכים, משימות, משתמשים והרשאות, שדות מותאמים ויומן פעולות.

## התחלה מהירה

נדרש Node.js 24 עם npm.

```sh
npm ci
npm run typecheck
npm test
npm run build
# במסד מקומי חדש בלבד:
npm run db:migrate:local
npm run dev
```

יש לפתוח את הכתובת המוצגת ולהתחבר. ההתחברות המקומית היא זהות בדיקה. סביבת הייצור משתמשת בהתחברות האישית של Sites.

## פריסה ועדכונים

- [הוראות התקנה, עדכונים, פריסה ושחזור גרסה](docs/DEPLOYMENT.md)
- [מבנה המערכת ומגבלות הגרסה](docs/ARCHITECTURE.md)

כל עדכון ב־main וכל Pull Request מפעילים בדיקות ובנייה ב־GitHub Actions. חבילת פריסה נוצרת ללא נתוני לקוחות או סודות. העדכון באתר החי מתבצע לאחר פרסום ל־Sites; push ל־GitHub לבדו אינו מפרסם את האתר.

## הגדרות נדרשות

קובץ `.openai/hosting.json` שומר את מזהה ה־Site ואת הקשרים `DB` למסד D1 ו־`BUCKET` לקבצי R2. תשתית Sites מספקת את ההזדהות והקשרים בייצור. לא נדרש סוד להרצת בדיקות GitHub; אין לשמור אסימוני פרסום או סיסמאות בקוד.

האתר והמאגר מיועדים להישאר פרטיים. פריסה מחוץ ל־Sites מחייבת התאמת מנגנון ההתחברות. GitHub Pages אינו יעד נתמך למערכת הזו.

## פקודות שימושיות

| פקודה | תפקיד |
| --- | --- |
| `npm run dev` | הפעלה מקומית |
| `npm run typecheck` | בדיקת TypeScript |
| `npm test` | בדיקות הרשאות |
| `npm run build` | בניית גרסת שרת ודפדפן |
| `npm run db:generate` | יצירת מיגרציה חדשה לאחר שינוי סכמת המסד |
| `npm run db:migrate:local` | הפעלת מיגרציות על מסד מקומי עם מעקב מיגרציות |
| `npm run release:package` | אריזת הבנייה והפקת פרטי מקור וחתימת החבילה |

## כללי שמירת מידע

אין להעלות למאגר מסדי נתונים מקומיים, גיבויים, מסמכי לקוחות, לוגים או סודות. מיגרציות קיימות אינן משוכתבות. שינויים בקוד אינם אמורים למחוק את הנתונים הקיימים ב־D1 או ב־R2.

גיבוי ושחזור ידניים זמינים בהגדרות המערכת. הגיבוי כולל רשומות ומסמכים עד 30MB ומיועד לאותה סוכנות; חשבונות צוות ויומן הפעולות אינם נכללים בו. יש לשמור גיבויים מחוץ ל־GitHub. גיבוי מתוזמן והתראות חיצוניות אינם מוגדרים בגרסה הנוכחית.
